Query any table with SQL. Even the big ones.

FROM   salesorder o
JOIN   account a ON a.accountid = o.customerid
WHERE  o.statecode = 0
ORDER BY o.totalamount DESC

About Hexa Studio

Hexa Studio is founded and developed by Truong Tan Dat, a Power Platform and Dataverse developer based in Ho Chi Minh City, Vietnam. It brings flows, web resources and the Dataverse Web API together in one fast desktop app, so makers and developers can review every change before it reaches their environments.
