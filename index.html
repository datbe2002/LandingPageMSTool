01 / SQL

Every table. Even the big ones.

Write T-SQL, press F5. Hexa plans it into FetchXML, reads large tables in parallel and streams rows into the grid as they land.

Reads
Any table, virtual ones included. The TDS endpoint takes over for what FetchXML can't plan.
Writes
INSERT, UPDATE and DELETE show how many records change and wait for your OK.
Editor
Monaco with table and column completion, tabs per environment, full history.

SELECT o.name, o.totalamount, a.name AS customer
FROM   salesorder o
JOIN   account a ON a.accountid = o.customerid
WHERE  o.statecode = 0
ORDER BY o.totalamount DESC

02 / FetchXML

Build FetchXML without typing it.

Pick a table, tick columns, join along real relationships — the XML writes itself. When you'd rather type, it completes every table and column name.

Builder
A tree of the query and a panel that knows your columns, relationships and choice labels. Operators fit the column's type.
Checks
Missing columns, wrong operators and aggregate mistakes are flagged before you press F5.
Results
Page through or load everything, count rows without reading them, open system and personal views, export to CSV.
